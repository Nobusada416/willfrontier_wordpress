# ウィルフロンティア コーポレートサイト
## デザインパターン 3 案 ご提案

3 つの方向性をご用意しました。
ご覧いただき、ご希望の方向性をお選びください。

---

# パターン A — 動画で魅せるタイプ

- ページを開くと、画面いっぱいに動画が再生されます
- 各セクションにも動画を多く配置し、動きで印象づけます
- 「動き」と「迫力」で会社の活気を伝える構成です

https://willfrontier-pattern-a.classic-market.jp/

---

# パターン B — 写真で魅せるタイプ

- ページを開くと、大きな 1 枚の写真がお出迎えします
- 動画は「再生ボタン」を押した方だけにご覧いただきます
- 落ち着いた写真の力で、現場のリアルな雰囲気を伝えます

https://willfrontier-pattern-b.classic-market.jp/

---

# パターン C — 写真の数で魅せるタイプ

- ページを開くと、6 枚の写真がタイル状に並び、ゆっくり切り替わります
- 別途「ギャラリー」専用ページがあり、写真を一覧で見られます
- 採用ページは、社員 3 名の顔写真とメッセージで構成しています

https://willfrontier-pattern-c.classic-market.jp/

---

# 3 案 比較

| 項目 | A 動画タイプ | B 写真タイプ | C 写真の数タイプ |
|---|---|---|---|
| ページを開いた瞬間 | 動画が再生される | 大きな写真 1 枚 | 写真 6 枚がタイル状に切替 |
| ミッション背景 | 動画 | 静止画 | 写真 3 枚を切替 |
| 採用ページ | 標準的なカード | 写真 6 枚のギャラリー | 社員 3 名 + メッセージ |
| 独自の見どころ | 動画の多さ | 写真ギャラリー | 専用ギャラリーページ |

※ ロゴ・ボタンの色（スカイブルー）・文字のフォント・黄色のアクセントは 3 案ともに共通
