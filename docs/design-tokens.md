# デザイントークン

定義場所: `web/app/app.css` の `@theme`。Tailwind のユーティリティ（例: `text-wf-navy`、`bg-wf-blue`）として使える。

## 色

旧 `style.css` の `:root`（`--wf-main: #4A9DBF` など）は、実際にテンプレートで使われている色と一致していなかった。
テンプレート内の出現回数をもとに次のとおり整理した。

| トークン                         | 値                    | 用途                                | 旧テンプレートでの出現回数 |
| -------------------------------- | --------------------- | ----------------------------------- | -------------------------- |
| `wf-navy`                        | `#2d5c8a`             | 見出し・強調文字・フッター背景      | 100                        |
| `wf-blue`                        | `#4a9db5`             | ボタン・英字ラベル・アクセント      | 78                         |
| `wf-ink`                         | `#374151`             | 本文                                | 14                         |
| `wf-border`                      | `#c8d9e6`             | 罫線                                | 8                          |
| `wf-surface`                     | `#f6f8fa`             | セクション背景                      | 8                          |
| `wf-royal`                       | `#003894`             | 濃紺                                | 7                          |
| `wf-orange`                      | `#d4874a`             | 下層ページの CTA ボタン             | 6                          |
| `wf-sky`                         | `#7fc8de`             | 淡いアクセント                      | -                          |
| `wf-deep`                        | `#1a3a5c`             | 暗い背景・オーバーレイ              | -                          |
| `wf-yellow`                      | `#ffe066`             | 黄色マーカー・下線                  | -                          |
| `wf-notice` / `wf-notice-border` | `#fef9e7` / `#f0d96a` | お知らせボックス                    | -                          |
| `wf-text`                        | `#2e5a6a`             | body の既定文字色（旧 `--wf-text`） | -                          |
| `wf-bg`                          | `#f5fafb`             | body の既定背景（旧 `--wf-bg`）     | -                          |

## フォント

| トークン    | フォント                                 | 用途                 |
| ----------- | ---------------------------------------- | -------------------- |
| `font-sans` | Zen Maru Gothic（400 / 500 / 700 / 900） | 本文・見出し（既定） |
| `font-en`   | Quicksand（300〜700）                    | 英字の見出し・ラベル |

## レイアウト

| トークン         | 値     | 用途                                        |
| ---------------- | ------ | ------------------------------------------- |
| `spacing-header` | `72px` | ヘッダー・フッターの高さ（`h-header` など） |

## ブレークポイント

Tailwind 標準（`sm` 640 / `md` 768 / `lg` 1024 / `xl` 1280 / `2xl` 1536）に統一する。
旧実装で使われていた 480 / 560 / 900 などの独自値は、近い標準値に寄せる。

高さの低い画面向けに `short:` バリアント（`max-height: 800px`）を用意している。
旧実装の JS による `transform: scale()` の画面収め処理は、これと container queries で置き換える。
