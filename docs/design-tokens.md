# デザイントークン

定義場所: `web/app/app.css` の `@theme`。Tailwind のユーティリティ（例: `text-wf-navy`、`bg-wf-blue`）として使える。

## 色

| `wf-blue`                        | `#2b7489`             | ボタン・英字ラベル・アクセント（旧 `#4a9db5`。P9 でコントラストのため暗くした） | 78                         |
| `wf-ink`                         | `#374151`             | 本文                                                                            | 14                         |
| `wf-border`                      | `#c8d9e6`             | 罫線                                                                            | 8                          |
| `wf-surface`                     | `#f6f8fa`             | セクション背景                                                                  | 8                          |
| `wf-royal`                       | `#003894`             | 濃紺                                                                            | 7                          |
| `wf-orange`                      | `#a95f27`             | 下層ページの CTA ボタン（旧 `#d4874a`。P9 でコントラストのため暗くした）        | 6                          |

## 重なり順（z-index）

`z-(--z-header)` のように使う。旧実装の `9999` / `99997` / `99999` といった値を整理した。

| トークン        | 値   | 用途                                               |
| --------------- | ---- | -------------------------------------------------- |
| `--z-header`    | `40` | 追従ヘッダー                                       |
| `--z-dialog`    | `50` | フォーム送信完了ダイアログ（P8）                   |
| `--z-menu`      | `60` | スマホ用メニュー                                   |
| `--z-intro`     | `70` | イントロ演出（P5）                                 |
| `--z-skip-link` | `80` | スキップリンク（フォーカス時にヘッダーの上に出す） |

## アニメーション

背景写真の切り替えに使う。旧実装ではページごとに名前だけ違う同じ keyframes を `<style>` で定義していた
（`heroFade` / `caseHeroFade` / `missionFade*` / `missionPageFade*` / `contactHeroFade*` / `vehHeroFade*`）ため、2 つにまとめた。
どちらも `motion-safe:` で付けるため、OS の「視差効果を減らす」設定ではアニメーションしない。

| トークン                | 内容                                           | 使う部品        |
| ----------------------- | ---------------------------------------------- | --------------- |
| `animate-wf-crossfade`  | 3 枚を 12 秒で一巡（1 枚 4 秒・フェード 1 秒） | `CrossfadeHero` |
| `animate-wf-tile-pulse` | タイルを順に明滅（周期・遅延は枚数から算出）   | `MosaicHero`    |

- `wf-crossfade` のキーフレームは 3 枚・周期 12 秒・フェード比率 1/12 を前提にしている。
  変える場合は `web/app/lib/media.ts` の定数（`CROSSFADE_FRAMES`・`CROSSFADE_CYCLE_SECONDS`・`CROSSFADE_FADE_RATIO`）もあわせて直す。
- 旧実装の 3 枚切り替えは切り替えの間隔が不均等だった（1 枚目だけ長く見えていた）ため、均等にした。
- 施工事例のモザイクは明滅の深さが少し浅かった（opacity 0.35 / scale 1.04）が、トップと同じ値（0.4 / 1.05）に揃えた。
- イントロの幕の色は `rgb(74 157 191 / 0.65)`（青）。テンプレートの指定はアンバーだったが、旧 `style.css` の上書きで青が表示されていたため合わせた（P5 ではアンバーで実装しており P6 で修正）。

## ブレークポイント

Tailwind 標準（`sm` 640 / `md` 768 / `lg` 1024 / `xl` 1280 / `2xl` 1536）に統一する。
旧実装で使われていた 480 / 560 / 900 などの独自値は、近い標準値に寄せる。

高さの低い画面向けに `short:` バリアント（`max-height: 800px`）を用意している。
旧実装の JS による `transform: scale()` の画面収め処理は、トップ（P6）では廃止して高さを中身に合わせた。
下層ページ（P7）で必要な箇所は、これと container queries で置き換える（`short:` はまだ使っていない）。
